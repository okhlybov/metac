# Fill autotest matrix/concept gaps + add value-type autotests

Three changes to `src/metac/autotest/` (auto-registered via the existing `walk_packages` import — no wiring needed), then full verification.

## 1. Matrix fills (`matrix.py`)

- **SBO vector row**: `Vector(name, element, inline_capacity=4)` as family `"inlined_vector"` over `("int", "comp")` — exercises the inline↔heap storage transitions (copy/move/swap/push/compact) that plain-vector rows can't reach; `comp` doubles as alive-counter leak canary.
- **`arc` kind extensions**: add `"arc"` to `stack`, `queue`, `dbuffer` rows (their default creates and push/pop protocols accept counted refs — plain vector/list/deque already prove the machinery).
- **`rec` kind extensions**: add `"rec"` to `stack`, `queue`, `dbuffer`, and extend `tiered` from `("int",)` to `("int", "cstring", "rec")` — rec/cstring have parameterless creates so the tiered growth path should accept them; **verification gate**: if generation or tests fail for tiered, drop tiered back to `("int", "rec")` or `("int",)`.
- pqueue/array/scbuffer/packet stay as-is (orderable/parametrized-create gates are legitimate).

## 2. Concept units (`concepts.py`)

- **`reserve`/`compact` units in `emit_sequence`**, next to the existing `resize`/`capacity` blocks, `active()`-gated (constraints evaluate at probe time, so flat_sets' new `moveable`-only constraint works): reserve(64) → capacity ≥ 64, contents survive, size unchanged; compact after growth → capacity shrinks toward size, contents survive.
- **Tombstone-compaction churn unit in `emit_set`**, gated on `ek.numeric and isinstance(T, IntrusiveHashSet)` (lazy import, circular-buffer precedent): ~200 put/remove cycles of distinct keys keeping size ~0, then assert `size == 0`, `t.tombstones < t.capacity` (struct field is accessible — proven by the earlier standalone stress), ghost-hit checks on a sample, then refill/verify. Locks in this week's compaction fix.
- **No container-level aliasing units** — deliberately: `Assignable.set`'s non-aliasing is a documented precondition, not a guarantee; testing it would enshrine UB. Aliasing coverage goes to the guarded paths in the values module below.

## 3. New `values.py` module (~350 lines, `at_`-prefixed types reusing `elements.py`'s `_cstring`, `at_composite`)

Condensed ports of the hand-written `metac.test` modules into the autotest `Type`/`unit` framework (snake_case, TAP-counted, run in CI):

- **String** (`at_string`): create/empty/size, format (simple, multi-specifier), self-referencing `format(s, "[%s]", s)` aliasing unit, copy+equal.
- **StringBuffer** (`at_string_buffer`, `scratch_capacity=16, chunk_shift=4` — small scratch forces the chunked/ownership-transfer paths): empty/size/view, push_char across the scratch boundary, push/push_slice, push_int/uint/long/ulong + push_double (formatting-gated), push_format (ret ≥ 0), take (+ `cstring_free` of the result — the destroy-returned-copy protocol), clear-and-reuse, copy with chunks (56-char push > scratch), move leaves source empty.
- **Option** (`at_int_option` over int; `at_int_state_option` with `states=3`): full ladder — empty/primed/state, set/overwrite, value/value_view, reset, emplace, equal (empty/engaged/mixed), copy (state+value), move (empty source), swap (post-bitwise-swap validity), hash, compare; state option: set_state transitions, reset-from-user-state.
- **IntrusiveOption** (`at_int_intrusive_option` with INT_MIN/INT_MAX sentinels; `at_cstring_intrusive_option` with NULL sentinel): raw-sentinel checks, set/primed/value (with explicit `cstring_free` of the returned copy — recently fixed leak pattern), overwrite-releases, reset, per-state predicate, copy replicates value *and* state, move leaves sentinel, equal/hash/compare ordering.
- **Variant** (`at_content_variant`, `{"amount": "int", "composite": Counted(at_composite)}` — check Counted ctor spelling at implementation): empty state, set/get per alternative, get_X_view, switch-away destroys (refcount release), re-set same alternative, **`set_X(&v, X_view(&v))` self-assignment guard no-op unit**, emplace_X, equal/hash for shared composites, copy (refcount increment), move (empty source).
- **BitArray** (`at_bitarray`, capacity 20, non-owning): none/any/count, set/test/clear/flip, set_all/flip_all (+partial), find_first (none/found), equal/hash/copy, full apply_*/create_* algebra (4+4) with inputs-unmodified asserts, is_subset.
- **BitVector** (`at_bitvector`, owning): empty/size, push/pop LIFO, reserve/compact, resize with word-boundary indices 63/64, set/get/clear_bit/flip_bit, set_all/reset_all/flip, find_first, copy/move, algebra with mismatched sizes (8/16, 12/8), is_subset.
- **Record** (`at_value_record`, `{tag: int, text: cstring}`): getter/view/setter roundtrip, **`set_field(&r, field_view(&r))` self-assignment no-op guard unit**, emplace_field (default-construct in place), member-wise copy/move/equal.
- **Emplacement extras** (the only test_emplacement scenarios the matrix can't reach): `Array` over cstring `emplace` destroying the previous element in place; vector-over-`at_composite` `emplace_back` with manual destroy of `get`-returned copies.

Expected unit count: 1987 → roughly 2350–2450 (+~300 from 9 new matrix cells, +~40 reserve/compact, +1 tombstone, +~75 values).
